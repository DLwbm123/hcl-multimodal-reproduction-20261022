# 通用多模态 HCL 新图像面板

固定 COCO、RefCOCO-UNC、VQAv2 来源、问题构造方式、原生像素协议和复现主评分。先合并原 pilot 与 native 的适应、验证和测试图像 ID，用种子 26112893 在补集选择四个任务各 100 条测试样本，每任务每图一条。面板只用于测试，样本 ID 及图像 ID 固定在 `PANEL.json`。模型结果不得参与抽样。

等同分割的 zero-shot 下限完整版完成并锁定后，在单卡 GPU 4 比较原裸 zero-shot、旧 Stability 恢复版最终 checkpoint、锁定路线与下限完整版最终 checkpoint。路线固定为检测、描述走旧 Stability，定位与 VQA 走裸路径，复用同批预测。下限完整版的裸分支复用完全相同的裸回答。四个系统只做推理，模型、组件、路由启用状态、记忆与已锁定路线不更新，推理缓存和日志放新目录。按任务计算相对裸路径的差和四任务均分。

新面板按图像在每任务内做 2,000 次配对 bootstrap，种子 26112894，报告分数及相对裸路径差的百分位 95% 区间。检测在重采样后重算原 micro-F1，定位与 VQA 重采样原逐例分数，描述重采样原逐例主分并固定面板参考语料的 CIDEr 权重。四任务均分为描述性均值。使用共享只读资源，以准备起算共享 24 小时硬时限和 2.5 GB 新增存储保护。仅公开程序、官方 benchmark 样本 ID 与聚合数据，答案和逐例输出仍在运行目录。
