# 三任务 HCL + LangGraph：工程整合验证

2026-11-09 完成。最终 v2 运行 EXIT=0，分类、定位、VQA 三阶段全部结束；真实 LangGraph 回合 63/63 完成，工具调用 63 次，控制器调用 126 次。12 个提示候选均生成并进入实际评测，3 次记忆候选均进入验收；最终全部拒绝，学习状态没有获得被接受的更新。

**结论是执行与候选验收流程已接通，不能据此声称方法有效、医学答案可靠或解决了遗忘。** 模型从始至终冻结。完成回合表示图执行产生了最终答案，不表示答案正确、工具选择合适或满足全部医学输出约束。

## 验证范围

- 外层直接执行原 `HCLPipeline.continual_train()`；内部最终作答由新 `GraphAgentModel` 执行真实 `StateGraph`。
- 三任务各 H-search/validation/anchor/test 1 例，共 12 个角色样本。样本由既有固定 Loader 顺序确定，没有因本轮表现替换。
- 每任务 4 个提示组件，各 1 个候选；保留严格收益、格式率和历史成功转失败为 0 的门槛。
- 工程协议预先将历史锚点最小总数和每任务最小数设为 1；旧三任务正式实验配置不变。如此微小的锚点规模不能支持可靠保持性结论。
- 三个工具共享一个本地冻结 Qwen2.5-VL-7B，通过不同任务契约调用。没有新增独立专家权重，也没有把胸片六工具移用于息肉图像。
- 图结构和工具代码固定。可尝试更新的是记忆与四类 HCL 提示；没有实现图结构学习或工具权重训练。

## 第一轮失败与修复

v1 虽完成三阶段驱动，但只有 19/62 个 Agent 回合完成，43 个失败：21 次提前作答、21 次动作字段不符合要求、1 次非 JSON。定位任务原生 bbox 输出与控制器额外的 `answer` 包装冲突；控制器指令也未充分隔离任务内部的“只输出答案”要求。另有 1 个提示 artifact 未通过结构验证。原始代码、轨迹和失败记录留存；初始协议见 `protocol.initial_v1.json`。

v2 将工具请求与任务最终答案分开：首步明确要求工具动作；取得观察后可直接返回分类标签、bbox JSON 或 VQA 原生格式。将控制指令置于任务内容之外、明确其适用步骤。非法工具请求仍拒绝，未放宽医学评分或候选接受条件。

修复后先用同样三个训练样本进行接口检查：三任务均实际完成工具调用及最终输出，输出格式也均通过。检查不以正确率选择配置。随后只复测一次完整三阶段流程，所有尝试共用原始时钟和累计调用预算。
