# VQA 局部记忆更新 v2（运行前冻结）

依据已完成的[v1报告](../vqa_continual_v1/REPORT.zh-CN.md)：全局更新的B=0门控保护A，但阻断B学习，C两个分支均未学到新知识。此轮检验局部修改是否在不放松B=0的情况下减少干扰，兼顾学习、保持并超过标准固定记忆。

## 机制与匹配对照

每批24个相同训练样本先从已提交状态生成一次标准反馈记忆与模型抽象提案。三个自适应分支各评估3个候选：仅raw、仅abstract、raw+abstract；各候选均相对同一批前状态，全部评估完最多提交一个。严格要求selection正确数至少+1、主分数增加、格式100%，保护分支旧正确转错为0，不用恢复抵消损失。优先当前正确数，其次旧损失更少，最后固定候选序号。

局部更新每批最多引入2条提案中新原始记录，按冻结训练顺序取前2。未满10条时添加，满时替换问题token Jaccard最相似的旧记录，平局按既有顺序，禁止淘汰本次刚插入记录；其他记录逐项保留。每阶段第一批只更新main_policy，第二批只更新failure_avoidance，另一抽象不变。该局部性约束也限制空状态的填充速度，需报告实际占用，不能把容量上限相同解释为实际记录数相同。

- Stability：上述局部更新，B=0。
- Plasticity：相同局部更新，B无限；单独归因保护门控。
- Bulk：相同提案生成、3种候选范围、评估预算、B=0，但对应raw/abstract库整体替换；单独归因修改范围。
- Fixed memory：保持v1标准配置，无条件完整批更新与固定词面top2，不优化、不搜索。
- Static / Direct：保持v1配置，提供不学习参照与答案接口诊断。

三个自适应分支都冻结原检索器和全部提示，不再优化memory_selector；没有阶段/类型检索过滤。raw上限10、abstract上限2、top2不变。权重、反馈来源、原生精确匹配、历史案例证据边界不变。每自适应分支6批、18个候选，共享同一调用上限；固定记忆不额外搜索，明确披露成本差异。

## 数据与独立性

沿用v1的288个开发组（每阶段train48、selection24、anchor24）；v1的216个报告组永不用于本轮独立确认。另从此前未使用的原train_replay角色按元数据抽取216组，**显式重新划为只用于报告的预留组**，每阶段72、每类型36；先写成员清单再关联答案。排除全部历史使用组及像素身份，原test不打开。此为新预留开发域留出集，不是原始validation/test；不能把v1/v2成绩当作同一配对集比较。候选只使用训练、选择及旧锚点信息。报告与新机制设计之间的独立性以本轮冻结为界。

A→B→C问题类型保持。六个条件从空状态开始，报告每阶段前后完整4×3矩阵；每阶段末对所有已学阶段的精确锚点独立核验，报告正确保护对象的分母及类型覆盖。零已学正确不算有效保持。

## 冻结终点与资源

联合目标：最终Stability比Static至少+5pp且配对95%下界>0；平均即时学习至少5pp；B和C均有正即时学习且接受更新；A、B均曾学到正确，最终各丢失不超过3/72；同时最终超过固定记忆且配对95%下界>0。局部机制额外要求相对匹配Bulk最终配对95%下界>0、旧例损失不增加、平均新学习不降低。全部条件同时通过才称完整联合成功；分项与全部负结果均报告。

20000次配对内容组bootstrap，种子2026102402，分阶段分层。单顺序、单种子，非患者独立临床证据。训练/选择、报告、锚点核验成本分开。

每自适应分支最多15000次模型调用，对照合计7000次；22.75小时软停、23小时硬截止，准备与失败重试共用原时钟。预计新增<1GB、4GB停写、5GB实验上限；复用模型/环境/数据只读，不删除历史。独立监督守护和一次30分钟监测；任一路失败停止本轮其他所属进程，不自动重启。

`prepare.py`冻结数据；`check.py`检验真实流水线配置、局部写入范围、门控与异常回滚；`supervisor.py`启动中性worker入口；`worker.py`运行；`analyze.py`仅在全体完成后审计与聚合。以环境变量RUN_ROOT、PREPARED_DATA、MODEL_ENV定位资源，不在进程argv暴露项目或用户标识。协议见[protocol.json](protocol.json)，真实启动时钟、冻结版本与检查记录由FROZEN/STARTUP_RECEIPT补充。

公开仅源代码、协议和汇总证据。私有成员、图像、答案、逐例输出、记忆状态及模型均不发布。

## 运行后补充分析（不替换冻结终点）

中间proposal/逐交互状态若未保存，明确标缺失，不能声称精确重建。后继诊断只用开发证据选择方案，先完成本轮最终报告push，再冻结后继数据、比较、预算和停止条件；本轮报告组不充当新独立确认集。
