# Task-scoped medical HCL

See REPORT.zh-CN.md for outcomes and limits. This is a task-aware adaptation, not exact paper reproduction. Source requires the shared medical_transfer modules, a prepared private dataset, frozen model, and campaign guard. Configure environment paths CAMPAIGN_ROOT, PREPARED_DATA, PILOT_PREPARED_DATA, MEDICAL_SOURCE, HCL_SOURCE, MODEL_PYTHON and NEUTRAL_WORKER. The prepare script preserves the original preparation-failure clock; it is an archival run script, not a new-budget launcher. No medical data, IDs, labels or model outputs are included.
