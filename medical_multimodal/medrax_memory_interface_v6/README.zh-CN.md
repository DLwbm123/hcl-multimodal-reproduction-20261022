本轮固定v5的H_A（同两条raw、同一条main_policy），只检验两个方法组件：原全局词面top2 versus 一条raw加一条abstract；历史裸字母答案 versus 其原训练问题中的对应选项文本。语义转换在选完记忆后执行，保证表示对照选择同一记忆。四个组合加不学习的H0，共五条件；均保留作者六工具、原提示、两轮流程与最终字母评分。两记忆槽不变，文本长度变化如实记录。

新抽取24个未用病例，A/B各12，排除此前148个病例及已知相同图像来源。成员先冻结，标签最后读取；没有选择集或运行中调参。每病例轮转五条件次序，每条件新会话，完整120回合分母。公开全部四个因子对比、准确率、首轮到最终选项变化、abstract实际曝光与成本；不凭单例改字母认定复制，不改用更有利的首轮评分。
