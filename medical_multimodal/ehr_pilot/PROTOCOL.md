# MedAgentBench v2 – procedural memory pilot (2026-11-26)

Use the prepared Stanford v2 data, reference scorer and official HAPI/H2 snapshot, with a loopback-only FHIR service. This is a development experiment on the public benchmark. No official untouched test split is claimed. Group by eval_MRN before allocation and omit cases without a patient identifier. Seed 261126. Within each of three disjoint patient pools sample 2 discovery, 2 selection and 4 later cases per family (20/20/40). Freeze IDs before scoring. Same ten workflows recur. Held-out patient transfer only.

Qwen2.5-VL-7B-Instruct in text mode. Shared official tool descriptions, eight decisions including FINISH, 384 completion tokens/action, max 24 most recent resource rows per GET, with truncation reported. GET uses the official local service, POST simulates the upstream receipt. Isolate runtime errors and grader errors from ordinary failures. A positive, an empty, wrong-subject, missing-field and duplicate-write fixture on task3 precede model runs. Repeat prior conditional no-action control against current service.

Discovery: one greedy and one sampled trajectory (T=.6) per case, identical action ceiling. Extract a short reusable procedure per instruction cluster using only discovery questions, observed actions/responses and terminal official/evidence-qualified correctness. Retrieval uses the closest successful discovery trajectory if available, otherwise closest failure, via lexical overlap of instructions after removing patient IDs. Archive full private trajectories. Match the extra memory context to 192 tokens for retrieval and learned text. Select the learned hint vs silence on the 20 selection cases, using paired outcomes pooled across families. Deploy the hint only for positive net evidence-qualified gains and at most one regression on selection. Freeze before held-out inference. Later cases: greedy no-memory, one additional independent sampled no-memory attempt, greedy simple retrieval and greedy selected procedure. Reuse identical greedy outputs for identical disabled policies. Primary: number correct on first attempt with required evidence for conditional tasks 5/9/10; also report official score, paired gains/losses, calls, per-family counts, and union of two no-memory attempts as an oracle retry ceiling. No verifier feedback at test time. For retention report changes on prior correct selection examples separately as in-sample preservation. No conclusions on new workflows or full continual training.

Here HCL-style credit is a trajectory outcome attached to observed steps, not action-level causal attribution. SkillOpt-style update is a validation-gated text edit, not the upstream optimizer. Hard wall clock 22h from first setup, expected incremental disk <10 GB; limit per file and check total space before phases. No model training, external APIs or live clinical writes.

Adapter correction before selection and later evaluation: render the documented API base in each function name. The initial discovery-only attempt that emitted literal placeholders is preserved separately. All arms restart from the original frozen split with the same patient groups and wall-clock origin.
