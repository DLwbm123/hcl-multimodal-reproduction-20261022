# 多步工具示范的呈现方式与触发时机

在原 35 个 UCI 构建患者上做五折内部诊断。每折 21 人提供示范、7 人选策略、7 人内部评估，每位患者仅在其内部评估折计分，共 210 题。此前独立验收的 21 人及门控的 14 人未参与。

| 策略 | 证据支持且答对 | 首步有效 READ | 非终止指令数 |
|---|---:|---:|---:|
| 无记忆 | 122 | 210 | 789 |
| 后置平铺示范 | 0 | 0 | 1081 |
| 前置平铺示范 | 0 | 0 | 1680 |
| 前置、保留历史对话角色 | 205 | 210 | 794 |
| 错误后仅提醒 | 122 | 210 | 789 |
| 同一触发条件下补入历史角色示范 | 125 | 210 | 796 |
| 开发侧选择策略、默认回退无记忆 | 203 | 210 | 795 |

前置平铺相对后置平铺改对 0、改错 0。保留角色相对前置平铺改对 205、改错 0；相对无记忆改对 85、改错 2，保住 120。这里的干预把示范动作和真实回执写进各自的历史消息，并将当前问题放在后面；不能把作用进一步窄化为某个标签。补救策略只触发 5/210，给示范比只提醒改对 3、改错 0、保住 122。

15 个折与题型组合中，14 个采用完整角色示范，1 个维持无记忆。被选策略相对无记忆改对 82、改错 1、保住 121。35 人中有 34 人净增、1 人持平，0 人净减；这与有一道单题改错相容。角色示范在数值题 189/193、缺值题 16/17；无记忆为 105/193、17/17。选择后分别为 187/193、16/17。按三种题型，角色示范为 68、70、67（各 70 题），无记忆为 57、37、28。相对始终使用角色示范，门控总分少 2 题。该研究说明示范格式和交互结构足以产生很大差异，尚未建立轨迹反馈编辑相对强示范的优势；这些病例曾用于定位问题，不能表述为独立外部验证。
