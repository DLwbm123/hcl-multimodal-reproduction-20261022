# 跨来源检验角色示范与基于工具回执的选择

采用 Zhao 等的上海糖尿病 CGM 数据，Figshare 21600933 v5，DOI 10.6084/m9.figshare.21600933.v5，CC BY 4.0。公开说明涉及 112 人的多个监测期。仅提取 Date 与以 mg/dL 标记的 CGM 数值，不将 CBG、用药或文字病历带入模型。患者编号跨访视绑定，同一患者全部监测期只能进入同一划分；各期单独计算、不跨访视拼接。有限、时间可解析的 CGM 读数按访视和时间戳去重，同一时间冲突值排除。不填补空数据。以本地钟点 06:00–09:59 和 18:00–21:59 定义早晚两个窗口，不解释为餐前。对每访视的首日、中间观测日、末日（去重）分别提最近七日早窗均值、最近七日与前七日全部读数均值差、最近七日傍晚与早窗均值差。截止锚点日终；评价为回顾性工具调用任务。每类糖尿病分别固定种子 26112710 洗牌，前40%作示范库，随后15%作门控（分别向下取整），余下患者独立验收。所有可用访视纳入，无法跨数据源匹配患者身份。

所有策略共用实际 READ、STAT、DIFF、八步上限、模型及有证据计分。A 无记忆；B 当前题以前平铺完整示范；C 当前题以前按真实对话角色呈现同一示范。初始示范按同题型和与锚点日历日期的绝对距离从构建库检索，固定次序破同分。D 以 C 开始；收到真实 READ 回执后，若当前示范中同一已查询组的空/非空结果与当前患者冲突，则选择同题型、其示范可见回执与目前已读各组空/非空均相符的最近构建示范。若不存在，继续原示范；一题至多切换一次。E 为匹配触发的对照：在同一前缀上按 D 的条件决定是否换示范，但一旦换，选择日期最近的另一示范，选择时忽略哪些回执相符。两组均保留当前患者已发生的工具历史，不预置读取，不使用当前答案。该消融检验一条研究者指定的回执归因与检索规则；未宣称复现 HCL 或原版 SkillOpt。开发选择只在门控集按题型判定 D 是否相对 C 改对至少一题且零改错，否则回退 C，冻结后用于验收。

主要比较 D 对 C、D 对 E 及门控选择对 C，次要比较 C 对 B、C 对 A；报告有证据与仅数值正确、逐题配对、实际切换数与触发后的配对、患者级方向、访视与缺值覆盖。若几乎没有触发则记为机制适用机会有限。示范库只用构建患者验证轨迹；源端与参考计算逐题一致才开始推理。保留本轮验收的独立性，不能用其轨迹改动本轮方案。三小时硬截止，450000 KiB 目录保护，累计新增占用严格低于 50 GB。
