# CGMacros 外部终止检查实验

45 名参与者，405 道回顾性查询。上海 43 名原构建患者中的 28 人提供角色示范，另 15 人 153 题决定三类查询是否启用检查。正式验收示范库使用全部 43 人。外部逐题参考值已通过独立直接计算和规范动作轨迹核对。

晨间均值 135/135，跨周变化 135/135，早晚均值差 128/135。外部触发 0/405，涵盖原来答对 0 题、答错 0 题。所有比较均改对 0、改错 0、保留 398，45 人分别持平。固定基线还剩 7 题的提升空间，原规则能触达的错误为零。协议保留未触发轨迹，三种后续提示在外部没有实际分叉，因此本次无法估计模型读到不同提示后的效果。

上海门控的三个题型各 51 题，基线分别答对 50、51、49。触发 2/153，均是原先答错的题；两种提醒均未纠正。两例均在已有非空记录时提前报缺值，重试后仍未计算所需均值。另一例已经收到两个均值，将 DIFF 操作数写反，最后答案与错误顺序的计算器回执一致。三类启用条件均未满足。这里的动作归因来自上海开发侧。CGMacros 的七个错误只按预设题型统计。

本实验只评价公开传感器序列上的有依据查询能力。基础数据采用 PhysioNet CGMacros 1.0.0，DOI 10.13026/3z8q-x658，CC BY-NC-SA 4.0。公开内容为协议、源码和聚合，不含个体数据或轨迹。完整汇总见同目录 result.json。

复现时将 sensor_context/run.py 映射为 sensor.py，diary/engine.py 映射为 engine.py，沿用其余 compare、pilot 环境与模型；source 指向已准备的上海构建目录。用 download.py 将所需 CSV 解到私有目录，source.py 转为 external.json；将本目录 run.py 映射为 t.py 并在私有目录运行 launch.sh，四个参数为设备序号。
