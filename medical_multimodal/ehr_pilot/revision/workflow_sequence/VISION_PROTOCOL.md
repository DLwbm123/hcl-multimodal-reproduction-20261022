# 影像迁移的配对诊断

把「依据当前回执选择后续技能，并将实际参数绑定到当前对象」用于影像二选题。首轮统一读取当前图像的视觉描述。随后可直接作答、固定中央裁剪后作答或匹配当前目标并裁剪后作答。裁剪工具只允许有效像素坐标，带原图框与真裁剪共同输入冻结视觉工具。固定策略、最近轨迹检索和按反馈归纳的条件技能复用同一定位、描述、作答接口，后续动作最多一次。候选训练时用所有反事实动作的最终参考正确性，按提问含空间提示和首回执是否不确定归纳后续动作。分层至少六例，否则用构建全局动作。相同收益优先较少调用。

- 历史 VQA-RAD 200 个已评来源仅用于拟合和门控，从可用二选病例中固定种子取至多 90 例，按约 2:1 拟合与验收。独立于该历史面板的 VQA-RAD 来源组作冻结测试，逐组排除历史 200 个来源、与 MedCTA 或历史影像近似的样本，源组只取一图一题。患者和模型预训练暴露不可识别。报告实际冻结测试分母。
- 同一病例离线生成所有动作结果后，在未使用冻结测试正确性时拟合及门控。归纳策略必须比直接作答多答对，且不降低相对固定裁剪与检索的验收正确数才能保留。冻结测试同列所有方法，包括未通过门控的反事实。冻结测试的真值仅用于评分，不影响动作。
- 记录二选准确、改对/改错/保留、工具调用、非空证据、固定与目标框重合及答案是否改变。非空工具返回仅验证接口有效，图像事实正确性以数据集二选参考衡量，无独立阅片。候选针对当前图的局部观察，限于这个迁移探针。
- 使用 GPU 6、7 各一分片；复用现有权重和数据。硬截止 45 分钟，新增预计低于 100 MB，500 MB 提前停止。只公开协议、代码和聚合。

复现使用原影像外部验证中的 `acquire.py`、`grounding.py`、`observation.py`，其中旧分组脚本作为 `signatures.py`，模型像素配置沿用原 `design.json`。私有目录的 `history` 是历史 200 病例面板，`source` 是 VQA-RAD 原始数据，`old_data` 是 MedCTA runtime。中性启动入口为 `l.sh`，调用 `t.py freeze|infer|report`。
