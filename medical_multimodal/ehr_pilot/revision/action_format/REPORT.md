# 限制首个动作前缀的配对结果

在新一批 72 人上共完成 144 次推理，约 15 分钟。两组 72/72 首次动作和回执逐例一致，回执数值与源表一致。三个分支各 24 人。参考路径均通过。原卡和限制前缀组均为 0/72，改对 0、改错 0、共同成功 0；官方评分也都是零。

| 首次取证后 | 原卡 | 限制动作前缀 |
|---|---:|---:|
| 达到预设基础语法检查 | 5/72 | 11/72 |
| 以 POST 开头 | 5/72 | 61/72 |
| 以 FINISH 开头 | 2/72 | 11/72 |
| 其它前缀 | 65/72 | 0/72 |

限制组在需写入病例中有 18/24 次以 POST 开头，在有值无需写入病例中仍有 19/24 次，在缺值病例中是 24/24 次。事后分开核对地址与正文：61 次 POST 中 33 次正文可解析为 JSON，但无一同时满足预设的本地接口地址和正文检查。全部 11 次 FINISH 内含非空的 JSON 答案，未通过评分。两组全部 72 对首条回执都与源数据的完整可见数值顺序相符。前缀控制改善了表面语法，尚未学会在该基准上决定何时停止、何时写入以及如何填写接口。真实检验配合模拟医嘱。可公开数据为 result.json 和分支计数，病例与原始轨迹私有。

实现复核发现，受约束组 61 次 POST 的 URL 前都有额外空白。这是前缀解码实现带来的格式偏差，影响严格语法计数。事后仅去除 POST 与 URL 之间的多余空白，保留原轨迹其他内容，用原参考程序重放；原分数逐例复现，修正后所有分支仍为 0/24。11 次 FINISH 答案均未通过；参考程序也允许正确的单值答案，非空本身不构成错误。结果与复核入口见 audit.json、whitespace.json 及同名脚本。
