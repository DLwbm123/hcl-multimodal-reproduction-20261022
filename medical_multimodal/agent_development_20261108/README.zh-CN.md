# 24来源真实Agent开发接入

状态以STARTED/TOOLS_LOADED/PROGRESS/FINISHED/EXIT为准。24个此前固定的方法开发来源，每来源一题；39张图已本地OCR、去元数据、脱敏和逐图复核。原始题目和基准答案不改。四组共96个完整回合，不是96次模型调用。

H0使用共同修复后的原Agent；Raw使用旧48条来源库的题干Jaccard前两条，取消当前阶段标签选A/B库（明确的适配差异）；Fixed使用最佳focused操作，带静态适用范围、已有观察免重复和失败回退；Proposed_v0把此前6来源反馈选出的候选交给真实控制器，从当前问题/观察判断是否采用。两者都只在单图且目标是airspace opacity或consolidation的缺口上使用此窄技能，其他任务或多图回原工作流。

Proposed_v0的语义适用提示和接口边界由人工指定；本轮未学习逐状态动作收益或条件边界，未实现完整自动优化。结果只能说明真实控制器接入、反馈所选配置及其运行差异，不能把提示包装的收益称为条件策略学习贡献。若与Fixed行动相同，就如实保留；不得削弱Fixed。

所有组共用同一六工具原生MedRAX图、控制器、图像、视觉入口修复、单图准入与调用预算。无脚本填正确谓词。评分仅比较最终单字母与冻结基准答案，不使用旧自由报告否定解析器。24题全部保留分母，同时单列7个来源文字较一致但未独立医学裁定的题，以及17个监督仍有疑点的题。该分层为开发资料审查，不等于临床真值。

原96确认来源和48冻结开发评估均未使用。本轮不自动晋升或进入确认集，先核实最终任务gain/loss、实际操作触发、误伤、失败、费用和语义适用边界。底座参数与全部经验状态在回合间固定，没有在线更新。独立8小时硬时限，GPU1，remote4GB/local1GB停写阈值，低于50GB规则；共享权重只读复用，不新增副本，不终止他人进程。

完成后公开代码、冻结协议和脱敏聚合；图像、原题、答案、逐例轨迹、来源ID和记忆库私有。启动前CPU检查仅覆盖输入隔离、计数、匹配操作与失败分母；真实六工具加载及运行需看运行回执。
