800 张策略相对 80 张策略，主要测试面板 MAE 差为 +0.000272，按图配对 bootstrap 95% 区间为 [−0.000033, +0.000619]。把这 400 张全部复核，实测 69 张误差下降、323 张升高、8 张持平。此次 400 张取自镜像 test；前一轮报告的 400 张取自 val，本轮进入训练，两组绝对误差不能作同题比较。

800 张训练图中，第二分割器令 299 张误差下降超过 0.002，339 张上升超过 0.002。冻结选择器仍选了视杯置信度，最终拟合的每个叶节点预测收益均低于 0.002 的调用阈值。即使训练中存在有益复核，部署时这条规则也只会停止。三个允许复核的候选在 800 张训练图上折外平均收益均为负。现有特征与候选规则未稳定预测复核获益。

640 张策略相对 80 张策略，在同一 160 张上少复核 72 张，杯盘比误差差为 −0.001986，按图配对 95% 区间为 [−0.004043, −0.000011]。与首轮停止的误差差为 +0.000030，区间跨零。诊断均检出 9/16 阳性，阴性判对 137/144，逐图改对 0 张、改错 0 张；80 张对照复现历史结果。800 张策略没有在自身训练所含的这 160 张上报告诊断。

扩大的是 HCL 与 SkillOpt 的策略反馈，分割专家和视觉模型配置固定。眼底的 800 张比较同时引入了 val 来源的图像，兼有训练量与图像来源变化。诊断比较使用历史面板，以上结果亦未单独测定 HCL 或 SkillOpt 的贡献。
