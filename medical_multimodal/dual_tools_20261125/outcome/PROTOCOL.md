# MedCTA 工具返回的收益、采信与停止

## 问题和主比较

同一病例、原图和四工具环境中，检验以回答对错变化学习的 HCL + SkillOpt 策略能否超过修复局部定位后的无学习基线。冻结配置见 design.json。使用原 30 道反馈题、16 道验收题及 45 道已在此前轮次分析过的评估题。搜索轨迹病例不进入本轮。主指标是同题自动答对数，并报告把基线错误改对、把基线正确改错的病例数和配对精确双侧 McNemar 检验。验收要求候选答对数严格超过原基线；候选始终在 45 题独立运行，部署回退与候选的实际表现分别解释。既有 45 题仅支持探索性比较。

## 训练信号

冻结 Qwen2.5-VL-7B-Instruct、后端工具和评分模板。依据训练题的参考动作顺序，实际执行最多四步。每加入一条真实工具返回，用相同的问题、前缀、回答器和评分器产生并判断当时的回答。为每个转移生成四类反馈，即改对、改错、持续正确、持续错误。另记录本答案是否正确，以及当前答案错误时，其后实际走过的训练前缀有没有恢复正确。轨迹结束时标为后续未知。观察到后续纠正不等同于任意下一步都会使答案变好。

原生 HCL RawMemory 保存这一轮全部训练转移，AbstractMemory 提取指导及避错经验。编辑器使用原生抽象记忆、分工具结果计数和按结果类别取样的真实训练对照，各生成一条采信指令和一条停止指令，以 SkillOpt 原生追加接口应用到两个独立的技能。推理中依照相同工具和可见文本检索五条最相似训练记录，提供改对改错及后继收益的计数。评估病例的金标准仅在两组的答案固定后交给评分器。

## 评估策略和成本

1. 修复后基线使用原实验已完成的逐题预测和真实调用记录。运行前核对原实验成功退出、完整病例集合和基线答对数。其局部选择器采用带字母的实际裁剪预览，调用参数映射到原图像素。
2. 固定规则对照保留与候选相同的两个决策和草稿生成流程，依据初始通用采信、停止指令判断。这个对照用于区分增益是否只是来自增加中间回答和推理次数。
3. HCL + SkillOpt 候选使用从训练反馈得到的追加指令及检索计数。每次执行工具后，比较已有证据的草稿与加上本次返回的草稿，选择是否采信。结束时提交最近一次采信的草稿。路由器可以看到已经实际观察的返回，包括曾被拒绝的返回，回答器只用采信的证据。独立停止决策可以提前结束，也可以推翻基础路由器的结束建议并请求下一项可用工具。达到四次调用即停止；两组都不会使用将来才会得到的返回。
4. 三组均最多四次工具请求。中间草稿及采信/停止判断带来额外模型计算，模型前向次数不等价。两实验臂在同一题内共享完全相同的草稿及请求的计算结果，各自独立记录逻辑工具成本。

## 复运行

沿用 ../round2/REPRODUCE.md 的模型与 MedCTA 四工具环境。使用本目录 run.py、feedback.py、check.py 和 design.json；RUN_ROOT 中提供 tool_server.py，路径中提供 ../round2/med.py、adapt.py、../grounding/grounding.py，以及父目录使用的 shared.py、clinical.py、previous_learning.py 和原归档依赖。设置 PAIRED_RUN 为已正常完成的修复后基线运行目录。新建空的 RUN_ROOT，先运行 python check.py 后运行 python run.py。病例级反馈、原始图像、记忆及答案均留在私有运行环境中。

首次启动的代码把描述性结果标签与动作字符串直接比较，会让 HCL 内部的正确标志全部为假。该进程在产生任何评估成绩之前终止。修正后，增加显式校验确保 HCL 的正确标志与加入返回后的自动评分一致，沿用原起始时间和预算。

## 技能文本完整性复核

自由生成的两个追加条款在 115 个生成 token 的上限处断句。停止条款还同时把“另一工具可以解除剩余不确定性”列为停止条件。保留原始策略及结果。读取验收或评估分数之前，另冻结 design_bounded.json 和 clauses.py，作为同一批记忆的格式敏感性检查。四条完整采信备选分别强调具体证据、局部冲突的佐证、精确测量或部位、草稿间的事实变化；四条停止备选分别强调已回答问题、经验中曾被后续纠正、与基础路由器的分歧、明确的未解决事实。由冻结模型仅凭同一组真实训练转移和抽象记忆，各选一条完整文字，通过同一原生补丁接口执行。四条备选由研究者预先写定。两版并列报告。

重建此检查时，以 design_bounded.json 为 design.json，并将 OUTCOME_FIT_CACHE 指向完成 30 题反馈和记忆生成的原运行目录。源目录中的 HCL 原始与抽象记忆均为只读复用，不需要重新拟合或复制图像。analyze.py RUN_ROOT 输出无病例标识的汇总。
