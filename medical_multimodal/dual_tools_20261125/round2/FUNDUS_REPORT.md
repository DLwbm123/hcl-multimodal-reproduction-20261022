# REFUGE2 眼底复核实验

目标是判断学习策略能否从第一次分割的实际输出识别值得复核的眼底图。先执行局部对比度分割器，提取置信度、形状、边缘等数值，让冻结的 Qwen 查看原始局部图和预测轮廓叠加图。若调用第二个颜色分割器，则平均两者的逐像素后验概率并重新取区域。各策略最多调用两个分割器，评估时缓存相同输出以共享计算。下表给出各策略在实际决策下的复核次数。

使用镜像的 120 张训练两位分割专家，另用 80 张学习策略、40 张验收。工具与策略在图像级划分上训练，无患者身份用于进一步分组。80 张训练图的两种分割结果都有真值反馈。HCL 汇总经验，SkillOpt 追加所选的浅决策树编号；四个候选都在反馈集做了五折交叉验证。冻结模型选择 B，训练折外平均误差降低 0.000109；C 的折外降低 0.000359，但需要更多复核。选中的树只使用视杯置信度和视盘实心度（面积与凸包面积的比值）。当首轮视杯置信度高于约 0.825 且视盘实心度低于或等于约 0.9433 时复核。模型参与了规则选择，最终这棵树并未用到视觉模型的轮廓等级。

**新评估的 400 张。** 相对手设触发，平均绝对误差差值为 −0.000590，按图像配对 bootstrap 的 95% 区间为 [−0.001052, −0.000205]。17 张复核图中 12 张误差降低、2 张升高、3 张持平。若在同样的预算下均匀随机复核 17 张，依据两条固定分支的实际误差，期望全组误差增加 0.000094。全部复核时有 164 张受益、191 张受损，45 张持平。可见策略在该批图像上确实选中了一部分受益者，但全组改善很小。视盘 Dice 从 0.72938 变为 0.72935，视杯 Dice 从 0.67472 变为 0.67501。这 400 张使用分割标注评估，未评价疾病分类。

**既有的 160 张。** 53 张复核图中 16 张误差降低、26 张升高，11 张持平；全组 MAE 增加 0.001426，配对 95% 区间为 [+0.000175, +0.002807]。诊断判断改对 0 张，改错 0 张，两组检出阳性 9/16，阴性判对 137/144，平衡准确率同为 75.69%。40 张验收图有 11 张复核，MAE 从 0.05963 降至 0.05911，分类同为 37/40，满足预定验收条件。

**结论边界。** 该组合有能力根据首轮证据决定是否复核，在新 400 张图上测量有小幅改善。两个评估子集上的测量效应方向相反，复核比例也从 33.1% 变为 4.25%。现有结果不能外推出稳定的诊断收益，亦无法单独归因于 HCL 或 SkillOpt。规则、聚合结果及事后同预算随机复核期望均附在同目录。
