# MedCTA 证据驱动的多步工具选择

本轮在 91 道参考轨迹无需外部搜索的题目上进行。沿用 30 道反馈、16 道验收、45 道留出题。留出面板与早期方案相同。两个策略都可查看原图、问题及迄今真实返回。整图描述、局部属性描述、OCR 和计算器可用，每题最多尝试四次。相同的无效或重复请求照计决策成本，后端缓存相同请求。文字回答器只读问题和执行所得文本。冻结的 Qwen2.5-VL-7B-Instruct 也承担依据参考白名单/黑名单的自动评分，评分提示不含策略标签。本实验未进行临床人工判读。

反馈阶段按标注轨迹顺序尝试执行各步，118 条决策记录进入学习流程。HCL 构建原始与抽象记忆。编辑器读取覆盖不同转移的训练示例，追加一次原生 SkillOpt 指令编辑。候选每一步还检索一条阶段匹配的训练决策。进入验收前冻结全部规则，验收要求工具种类集合 F1 上升且答对数不下降。无论是否通过，两条策略均实际评估，以区分候选表现与部署结果。

| 指标 | 验收基线（16） | 验收候选（16） | 留出基线（45） | 留出候选（45） |
| --- | ---: | ---: | ---: | ---: |
| 自动判为正确 | 0 | 0 | 3 | 5 |
| 成功调用工具种类与参考的集合 F1 | 0.5000 | 0.5000 | 0.5348 | 0.5504 |
| 与参考工具顺序完全一致 | 0 | 0 | 0 | 0 |
| 每题平均请求数 | 1.81 | 1.00 | 1.64 | 1.18 |
| 无效请求总数 | 13 | 0 | 23 | 1 |

验收候选有 14 题仅调用整图描述，2 题仅调用 OCR，F1 持平，按协议继续部署基线。45 道留出题中候选改对 2 题、改错 0 题，配对精确 McNemar 双侧 p=0.50。第一题基线仅提出无效局部框，候选取得整图描述，随后也提出无效局部框。第二题基线仅读文字，候选选择了整图描述。两次纠正都伴随可用整图报告。该比较使用本轮重新运行的适配基线；上一轮的基线也是 5/45，两次运行的提示和动作约束不同。

**实际用到了哪些工具。** 留出集候选成功执行整图描述 40 次、OCR 12 次，局部描述尝试 1 次且坐标无效，计算器未被选择。最终 33 道只取得整图报告、5 道只取得 OCR、7 道取得 OCR 和整图报告。基线的 26 次局部描述请求仅 3 次成功。参考轨迹在 45 道中有 44 道包含局部描述，45 道均含整图描述和 OCR，没有计算步骤。参考工具是可核查的轨迹指标，不能直接推断每一道题在医学上都必须使用所有列出的工具。

**定位到的瓶颈。** 训练时生成的坐标常是自由文本，进入记忆的 28 条紧随局部尝试的训练状态全部显示无效框；即使知道下一步该调用哪个工具，也无法凭这些记录学到成功使用局部证据后的动作。候选减少了失败请求，仍主要依靠整图描述。现有结果支持优先验证局部框生成、实际裁剪返回和定位质量，并未验证可稳定提高答题率的多步技能。后续若对定位参数作修复，应在反馈题单独验证，再用新的评估材料确认，以免把同一留出集反复用于选方案。
