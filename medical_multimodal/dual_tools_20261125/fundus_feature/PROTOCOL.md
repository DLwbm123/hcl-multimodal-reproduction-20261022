# REFUGE2 反馈数量与选择性复核

用相同的眼底图、分割专家、动作和参考掩膜，检验增加策略反馈样本能否帮助判断何时停止。第一次调用固定的局部对比度分割器；复核时再调用颜色分割器，平均两个后验概率并测量垂直杯盘比。主要评估是既有 400 张图上的杯盘比平均绝对误差。另列 160 张有青光眼标签的历史评估图，报告误差、平衡准确率和配对改对改错数。两个面板在此前都已分析过，按图像划分，缺少患者关联。

两个专家始终用原来相同的 120 张拟合，策略使用独立的 80 张或其分层 30 张子集。30 张包含 3 张阳性、27 张阴性。主子集种子 31，另列 32、33 检查抽样敏感性。所有设置均由 design.json 在运行前指定。40 张验收要求相对直接停止的杯盘比误差下降且平衡准确率不降。无论是否通过，报告原始候选在评估面板的结果，同时标记验收状态。

对每张反馈图直接比较初始与复核输出离标注杯盘比的绝对误差。把首轮可得的视杯置信度单列一组，视盘实心度、视杯实心度、初始杯盘比列为形态组。只有在折外评估中，联合特征和仅该组都提示复核，去掉该组后不再提示复核，且实际复核使该图误差下降超过 0.002，才把该组记作能够区分是否该复核的特征。此标记刻画该组在拟合路由器中的预测作用，不能推断单个解剖特征的临床因果作用。

原生 HCL 记录每张反馈图的首轮特征、实测损益、折外动作和归因，并形成抽象记忆。四个有界动作规则为停止、依置信度复核、依形态复核、依联合特征复核。冻结模型根据 HCL 摘要、拟合规则及五折收益选择一项，SkillOpt 原生追加补丁使该规则生效。不同反馈量采用相同协议；树的叶样本下限按训练折大小的相同比例确定。该比较验证整个组合的行为，未单独消融 HCL、SkillOpt 或学习树。

评估时先在固定模型上重新生成首轮分割和特征，冻结所有动作后读取此前保存的首轮/双专家实际结果，按图验证首轮杯盘比一致，再计算候选在其所选分支上的结果和实际逻辑调用次数。复核指标和同图 bootstrap 沿用 round2/eye.py。复跑时使用 round2 已建立的 REFUGE2 环境和依赖，把本目录 run.py 与 design.json 放入新 RUN_ROOT，指定 PRIOR_RUN 为先前完整的眼底复核运行，再用原 start.py 启动。

HCL 写入使用 dual_tools_20261125/previous_learning.py 的 capacity 接口，把容量设为本组反馈图数。首次执行时旧眼底目录里的接口缺少该参数，拟合阶段报错；换为项目已有的完整记忆接口后，在原截止时间内重跑。这个修复发生在验收和评估前。
