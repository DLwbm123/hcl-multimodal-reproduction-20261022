# Sol High 订阅控制器：作者六工具医学 Agent 基础验收

按用户要求，用本地 ChatGPT 订阅的 **gpt-6.1-sol / high** 替换作者 GPT-4o，先完成不带 HCL 的 MedRAX 基础验收，再考虑持续学习。该目录不改变此前 MedRAX/ReAct 失败记录。

已完成 CLI 修复及真实订阅测试：纯结构化回复、图像识别后的工具选择、匹配工具结果的消费均通过；后两项证据见 [TRANSPORT_RECEIPT.json](TRANSPORT_RECEIPT.json)。原生 Agent 的工具调用 ID、ToolMessage 回传、第二轮 MemorySaver 状态与冻结面板图片的 CPU 检查通过。bitsandbytes 0.47.0 的微型 CUDA 8-bit 前向也已通过；Triton 缺少 Python 头文件的问题通过只读复用匹配头文件解决，修复与验证回执一并保留。

作者 `dae30e2f136ef0b2a40885a4c335386e9ffad052` 的 `experiments/benchmark_medrax.ipynb` 使用六个工具，按原顺序为报告生成、分类、分割、MAIRA-2 定位、CheXagent、LLaVA-Med。MAIRA-2 和 LLaVA-Med 使用作者的 8-bit 加载配置。保留原系统提示、问题提示、LangGraph 工作流及第二轮只答 A–F 的评分流程。

必要差异是：Sol High 替换 GPT-4o；订阅 CLI 不提供原 `temperature=0.2/top_p=0.95` 控制；工具协议经结构化 JSON 转为原生 AIMessage，平台仍保留 CLI 封装。关闭宿主工具、网页、技能和记忆，并以本地沙箱隔离标签路径。图像通过本地附件传输，在原分辨率转换为 RGB PNG；原数据保留。不能将这些配置称为作者同模型数值复现。

## 冻结范围与状态

从未用于此前 48 病例实验的病例中，按 seed 20261026 和元数据类别选择 12 个不同病例，共 19 张图像；成员清单私有且已在推理前冻结。每例新建会话，不跨病例学习，不引入 HCL。全部病例保留分母，答案和解释不进入模型或工具，整批结束后才评分。

MAIRA-2 官方授权已取得。两个新增模型共 17 个文件、42,654,412,633 字节已下载完成；原四工具权重、CLIP、数据与环境只读复用。六个原生工具均已加载并独立预检成功。首轮病例运行发现传输缺陷：控制器返回本机附件临时路径，远端病例路径白名单将其拒绝；已观察到的 55 次自主工具调用全部因此失败。该轮在评分前停止并完整保留，不作为医学验收通过证据。

现已增加附件路径到对应原始图片路径的精确映射，仅转换工具参数中的已知别名，保留未知路径拒绝边界、图像顺序、问题文本和原始模型输出。修复后重新执行相同冻结面板，病例、提示词、工具设置和评分规则不变；原始时钟与 200 次调用上限不重置，修复重启时累计预留调用 77 次。详见 [PATH_TRANSPORT_INCIDENT.json](PATH_TRANSPORT_INCIDENT.json)。修复后六工具重新预检全部成功，首例自主调用 CheXagent 成功，结果已进入下一次成功完成的控制器请求，实际图片参数映射得到验证。**整批 12 例现已完成，11/12 正确，工程验收通过；工具内容存在低信息与破损输出，不据此声明工具增益、医学有效性或 HCL 有效性。** 完整结果、失败与成本见 [REPORT.zh-CN.md](REPORT.zh-CN.md)。
