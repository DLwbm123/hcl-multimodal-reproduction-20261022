# 同一定位框下的 SAM 多候选分割复核

在原息肉 T2 数据和冻结模型上，用 Qwen 预测的初始框只调用一次 SAM，同时保留原始三张候选掩码及其模型评分。默认策略选 SAM 预估质量最高的掩码。复核策略把原图和三张候选轮廓放在一张图板上，候选顺序事先固定随机种子打乱，不显示模型评分。Qwen 在不知道真实标注的情况下选择 A/B/C，拒答或无法解析时沿用默认掩码。评估沿用原任务的 Dice、面积误差、合法性和成功条件。事后分别计算两种动作覆盖的上限、以及允许逐例从原始三个候选中任意选取的上限。

预设触发信号是最高两项 SAM 质量分之差、最高两张掩码的相互 IoU 以及两者的交集。训练组、开发组及停止条件见 design.json。研究只用于检验是否有值得学习的复核行为，不做临床效果或长期遗忘推断。配对诊断为了获得两个结果会执行全部复核；各策略成本按真正触发复核的次数计算。

`python3 -B check.py` 可检查训练选择和策略成本。真实运行复用同仓库 `medical_multimodal/skill_edit_20261125/launch.py` 以及原私有试验环境和数据目录，GPU 启动方式同定位诊断。

## 实测结果

12 个训练来源组中，按 SAM 评分默认选择的平均 Dice 为 0.7012，全量视觉复核为 0.7015，成功数均为 7/12。Qwen 的 12 次选择都能解析，其中 7 次改选其他掩码，但没有一例的 Dice 改变量达到正负 0.05，成功状态也没有翻转。每例全量复核额外消耗一次 VLM 调用。

即使事后逐例在两个动作中选较好者，平均 Dice 也只有 0.7032，相对较好的固定策略仅高 0.0017。若允许用真值从所有三个 SAM 候选中选最好掩码，上限为 0.7131，比默认策略高 0.0119。12 例中有 11 例的评分前两名候选掩码相互 IoU 超过 0.75。候选虽有不同编号，产生足以改变分割结果的差异有限。

训练选出了“最高两张掩码相互 IoU ≤ 0.75 时复核”的规则；仅触发 1 例，平均 Dice 为 0.7016。逐来源组留一重选策略得到 0.6995。依据运行前规定的停止条件，未开启开发评估。当前小面板支持以默认 SAM 选择作为固定流程，尚未提供验证技能优化与保持所需的决策差异。
