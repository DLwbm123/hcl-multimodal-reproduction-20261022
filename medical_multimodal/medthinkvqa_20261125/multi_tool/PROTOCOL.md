# 多工具取证与跨病例学习

本实验独立于单工具实验的通过或失败。问题是面对一笔固定的取证预算，HCL 经验或 SkillOpt 技能编辑能否教会冻结模型选择合适的视觉操作，并在新病例上多答对。所有学习组和无学习组拥有相同的工具、候选参数及调用机会。三个工具都返回实际的图像像素。

| 工具 | 可执行的操作 | 限制 |
|---|---|---|
| open_view | 从病例目录中取一张尚未读过的原图，保持比例展示 | 看不到未打开图像的像素 |
| inspect_region | 在一张已打开的原图中，裁剪中心或指定角部并放大展示 | 五个预设范围，放大不能恢复原图缺失的细节 |
| compare_regions | 截取两张已打开原图的同一相对区域，拼成左右对照图 | 需要已打开两张图，相对位置不代表解剖配准 |

每个病例统一先打开第一张图，随后再执行两次视觉操作，最终只诊断一次。每次操作返回一张 560 × 560 画布。每步先选择操作再选择参数，两步共四次冻结模型前向，加一次最终诊断。每例每组都产生三张观察图、五次模型决策。不同策略可以实际使用一至三张不同原图，这正是要检验的取舍。

主要比较是同样拥有三个工具的无学习、HCL、SkillOpt 和联合方法；另设固定程序，依次打开头两张图并对照中心区域。固定程序也执行同等预算的影子决策。各组记录动作类型、实际参数、原图集合、最终诊断，以及相对无学习组的改对、改错和净增病例数。

从固定去重病例池排除第一轮 96 例，再排除单工具学习实验的全部 192 例。取其后每阶段 16 个反馈病例、16 个验证病例和 64 个独立确认病例。两个实验的独立确认组不同，不能直接相减准确率来估计“额外工具”的因果效应。本实验内方法间的比较全部逐例配对。更新规则、验收标准、确认标签隔离与上级 learning/PROTOCOL.md 相同。主要检验是联合方法对同工具无学习组。

复现时使用上级 learning 目录的 run.py 和 panels.py，替换为本目录的 design.json、check.py，并增加 visual_ops.py，沿用同一模型、启动器和只读原数据目录。像素级小样检查覆盖取新图、局部裁剪、真实拼图和固定预算。运行不访问外部诊断服务。
