# 多工具条件下的 HCL 与 SkillOpt 确认结果

在独立确认的 128 个病例上，无学习组答对 47 例，HCL＋SkillOpt 答对 47 例。联合方法相对无学习组改对 5 例、改错 5 例、净增 +0 例。双侧精确 McNemar 检验 p = 1。未达到预先设定的初步支持标准。

| 部署状态 | 答对 | 改对 | 改错 | 净变化 | 操作类型序列改变 | 使用过裁剪或双图对照的病例 |
|---|---:|---:|---:|---:|---:|---:|
| 无学习 | 47/128 | 0 | 0 | +0 | 0 | 0 |
| HCL | 48/128 | 5 | 4 | +1 | 0 | 0 |
| SkillOpt | 47/128 | 0 | 0 | +0 | 0 | 0 |
| HCL＋SkillOpt | 47/128 | 5 | 5 | +0 | 0 | 0 |

固定执行“打开首图、打开第二张图、并排查看中心区域”的对照答对 48/128。每个病例均采用三次取证操作和五次病例模型决策。

## 更新与保持

- HCL 接受更新的阶段为A。在 64 个新 A 病例上，A 后和 B 后的状态分别答对 22 和 22 例。最后候选单独使用时答对 48/128，相对基础状态改对 6、改错 5。
- SkillOpt 接受更新的阶段为无。在 64 个新 A 病例上，A 后和 B 后的状态分别答对 20 和 20 例。最后候选单独使用时答对 46/128，相对基础状态改对 1、改错 2。
- HCL＋SkillOpt 接受更新的阶段为A。在 64 个新 A 病例上，A 后和 B 后的状态分别答对 20 和 20 例。最后候选单独使用时答对 47/128，相对基础状态改对 5、改错 5。

候选验证记录、各阶段确认结果和诊断性比较见 result.json。操作路径与答对变化的描述性对照见 action_analysis.json。两阶段各有 16 个反馈病例和 16 个验证病例，最后每阶段另有 64 个从未用于学习或验收的确认病例。此轮和单工具学习实验用了不同病例，两轮准确率之差无法单独归因于工具数量。

实际执行 5,430 次病例选择或诊断前向、12 次学习文本生成。相同冻结状态的重复预测复用。病例、草稿及逐例预测保留在服务器私有目录。

确认组的四个自主策略在全部 128 例中都连续选择打开原图。相对无学习组，联合方法在 100 例改变取图参数或先后顺序，这些病例中改对 5 例、改错 5 例。只有固定顺序对照按预定流程使用了双图对照。动作菜单固定把 open_view 放在第一项，当前实验没有将首项位置偏好与实际工具偏好分离；这些数据无法判定局部工具对诊断本身有没有价值。
