# 原生 ReAct 视觉工具资格检查：未通过并关闭

本轮 12/12 病例执行结束，4/12 答对、6/12 有效最终选项，**0/12 自主视觉工具调用**。原生图像描述、区域描述、OCR 和 Calculator 的直接预检全部运行成功，但预检不计自主工具成功；冻结门槛要求至少 6 个成功视觉工具病例，因此未通过。未启动 HCL，未测保持能力，不存在 HCL 增益结论。

## 发生了什么

12 个病例均只调用控制器一次，随后通过原生 FinishAction 结束；没有工具解析失败或工具执行异常导致的零调用。6 个无效最终答案主要表示缺少可见图像。4 个正确答案均来自文本推断，不能视为视觉能力证据。代码检查显示原生 ReAct 格式化保留两个用户消息，图片路径和工具清单均在输入结构中；没有发现接口丢弃它们的证据。模型是否实际关注这些内容，无法由此确认。

原始 LLaVA 工具在直接预检中确实接收两次 `[1,3,336,336]` 像素张量并完成生成。预检仅覆盖一个图像；工具可执行并不代表医学描述正确，观察到的描述也不足以支持可靠医学视觉能力。

## 成本与失败记录

- 智能体阶段：12 次控制器生成，9,905 输入 token、1,795 输出 token；零工具调用、零视觉生成。
- 单列直接预检：4 次工具调用，其中 2 次视觉生成，98 输入 token、146 输出 token；约 5.73 秒工具墙钟时间。
- 前三次环境构建失败均在真实生成前终止，各保留 12 个 not_run 记录。原因依次为缺少 pycocotools、自动 SDPA 不兼容、eager 配置被模型构建步骤覆盖。
- 第四次修复以进程内工厂将 eager 显式传给模型构建。原始协议 b4ecb2c 未改变，最终兼容性源码 ca5e415。共享环境和原始工具算法未改动。
- 原始一小时预算包含全部准备和重试；首次开始至最终控制器退出约 55.60 分钟，退出早于 02:42:14 截止。退出码 2 表示资格门失败，并非本次未完成推理。
