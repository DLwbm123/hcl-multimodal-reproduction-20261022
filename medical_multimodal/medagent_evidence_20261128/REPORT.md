# MedAgentBench 两来源取证最小验证

## 任务与预算

用 MedAgentBench v2 官方 FHIR 快照，构造固定的回顾性取证任务。每个窗口可以从检验工具取得一条血糖记录，或从生命体征工具取得一条血氧记录，任一来源有合格数值即可成功。固定 Harness 先提供目标窗之前 48 小时的历史索引，策略只能再查一路。工具查到后由同一个执行器提交记录，使用真实来源、患者绑定、数值和时间窗校验。GLU 与 SpO2 都来自同一官方快照，属于两种搜索工具的观察记录；本实验是单个后续动作、只读回放。

从 300 道官方题中提取 98 个非空且不同的患者标识，用 54/20/24 位患者做训练、开发、留出分区，每位固定四个截止点。窗口不按可用性筛选。不同分区没有共同患者。由于复用公开快照，不推断这些患者从未被历史实验或预训练访问过。回放查询命中了时间窗内的 FHIR 记录并按本地时间戳复核。响应未送入任何外部服务。

## 动作选择上界

| 策略 | 开发 20 人、80 窗口 | 留出 24 人、96 窗口 |
|---|---:|---:|
| 固定检验 | 57/80 | 62/96 |
| 固定生命体征 | 58/80 | 65/96 |
| 按训练侧拟合的固定截止点策略 | 58/80 | 64/96 |
| 历史索引的最近记录规则 | 58/80 | 65/96 |
| 分区内事后最佳固定截止点策略 | 59/80 | 65/96 |
| 按病例枚举工具的上界 | 60/80 | 65/96 |

事后固定参照可为每个截止点选择同一来源服务所有患者，用于保守测量潜在空间。病例上界允许每个窗口选择能取到记录的来源，其计算枚举两个动作，部署仍限一次调用。

开发集两路都能取到 55、都取不到 20、只有检验可用 2、只有生命体征可用 3。上界较事后固定参照多 1/80，收益仅涉及一位患者。留出集两路都能取到 62、都取不到 31，余下 3 个全是只有生命体征可用。固定生命体征完整覆盖可成功窗口，上界净差为 0。训练侧也只有 12/216 个窗口的两路动作回报不同。

## 判定

开发侧没有达到预先固定的至少 5 个百分点、至少两位患者获得额外成功的门槛。留出诊断也显示零上界差距。本任务的限制是两路在当前成功定义下的可用性高度重合。冻结模型、SFT 和 GRPO 的 GPU 对照因此未启动。

标准库环境自检覆盖时间边界、来源选择、预算外动作、索引屏蔽和 SpO2 文本数值解析。原快照隔离副本的 FHIR 采集及 CPU 上界评估完成，服务已退出。只发布源代码、协议和聚合指标，患者清单、回执和逐窗口结果保存于私有运行目录。

两种训练目标均用合成的 CPU 两动作样例核对了梯度方向；该检查没有使用模型权重，也没有代替 GPU 对照。
