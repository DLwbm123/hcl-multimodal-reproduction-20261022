# v7：完整原始输入对照与独立参数映射诊断

**完整事实可见使导航任务从 A 的 3/12 提升到 B 的 9/12；独立映射数值正确 6/6，证据审计后可信正确 4/6。**本轮完成全部 30 个任务，状态为 `COMPLETE_AUDITED`。结果支持有限输入获取是当前瓶颈之一，同时明确留下冲突处理、患者/就诊范围判断及派生参数证据链问题。没有启动 HCL，也没有重写 v5/v6 的历史成绩。

## 冻结设计与实际执行

首次推理前，协议、用例、评分和预算冻结于源码提交 `79617bd029f11701623c64ef51276dac916b7ac5`。使用 Qwen2.5-VL-7B-Instruct，BF16、SDPA、greedy 解码、32768 上下文和原 Qwen-Agent Nous 传输；没有增加生成约束或事后修补输出。

- 导航：12 个新合成用例，各 12 条事实。8 个可作答，2 个确实缺失，2 个存在冲突；覆盖首、中、末页、多字段分散、重复一致记录及跨患者/就诊干扰。
- A 自主导航：初始无已读事实，模型决定读取和终止。
- B 完整事实可见：程序在首次模型调用前按固定顺序读取所有原始页面，保留全部干扰及冲突记录。模型仍自己选证据或弃答，程序不提供正确 ID、参数或答案。
- 配对两组的任务提示、SYSTEM、工具 schema、执行器、评分和每例 12 次模型调用限额相同。每例使用全新状态，奇数用例 A→B、偶数 B→A；每两对穿插一个映射任务，没有成绩门槛阻断。
- 映射：独立运行 v6 从未进行模型推理的六个小型合成用例，均采用 B 输入条件。模型自行读取公式定义、生成绑定、执行并显式提交。

5 项 CPU 检查通过，模型调用为 0。运行后核查了实际配对 prompt 相同、A 初始已读集合为空、B 初始可见行与原始输入完整对应且未经筛选。完整输入也会改变上下文长度及读取状态，这是输入获取干预的一部分，并非等 token 成本比较。

## 独立映射与全量计算审计

六例均读取了公式定义、产生一个被执行器接受的计算并显式提交，全部六个计算的参数、来源和转换说明已人工复核。不能将执行器接受或最终数值正确等同于可信正确。

| 用例 | 任务 | 数值正确 | 可信正确 | 审计结果 |
|---|---|---|---|---|
| M01 | Anion gap，输出 14 | 是 | 是 | 三个输入值与各自直接来源一致 |
| M02 | Anion gap，输出 15 | 是 | 是 | 三个输入值与各自直接来源一致 |
| M03 | MME，输出 22.5 | 是 | 否 | 日剂量 15 数值正确，但只引用每次剂量，遗漏每日频次 |
| M04 | MME，输出 30 | 是 | 否 | 日剂量 20 数值正确，同样遗漏频次来源 |
| M05 | RASS，输出 +1 | 是 | 是 | 原始事实显式包含 Restless (+1)，来源与定义相符 |
| M06 | RASS，输出 0 | 是 | 是 | 原始事实显式包含 Alert and calm (0)，来源与定义相符 |

M03/M04 的 `daily_dose_mg` 都只引用 `fact_0002`，没有引用 `fact_0003` 的每日次数，且把数值转换说明写成 `lower`。药名小写化可以用该说明，但剂量乘频次不能。因此，这两例是**数值正确但证据依赖不完整、转换说明不成立**，不能推断为不会乘法，也不能补写来源后将其改判通过。

M01/M02 的转换说明只有单位 `mEq/L`，M05 只有类别 `restless`，解释都很简略；由于它们是原始字段中显式给出的同单位数值或显式分值，来源和值直接一致，未发现错误转换，保留可信正确。此判读不应外推到需要多来源计算的派生参数。

B 导航在程序预读之后，模型又发起了 27 次读取，均为已读页面的重复访问；A 导航有 22 次模型读取。**本轮 B 提高正确率，但没有降低调用或 token 成本。**序列化 bytes 是自动读取回执大小，不是网络流量或新增模型 tokens；预读事实进入模型上下文的成本已经计入输入 tokens。

16 次无效调用包含 **9 次 JSON 语法错误、7 次 schema 错误**。其中 15 次发生在映射任务，1 次为 C12_B 的重复事实 ID。映射的 6 次 schema 错误包括空转换说明及缺失/错误字段；9 次 JSON 错误来自缺少结束符。另有导航范围错误 4 次，均为合法格式进入执行器后被拒绝，单独计数。所有失败调用保留在原始账本及成本中；模型在同一预定任务内按反馈修正，不等于另起实验重试。

首次尝试到 worker 退出约 **125.38 秒**，到 supervisor 退出约 **130.43 秒**，含模型加载；预注册上限为 45 分钟、360 次请求、300 万输入/25.6 万输出 tokens。三份调用账本与 30 个任务计数完全对账，没有额外模型 smoke、重跑或未尝试任务。

交付前远端运行目录实际分配 1,294,336 bytes，中性入口 8,192 bytes；最后一次运行期检查含保守余量为 1,076,080,640 bytes，低于 2 GiB。小型交付文件计入预留空间，共享模型、环境及 v5/v6 只读复用。worker/supervisor 均退出码 0，身份核查与 GPU 列表确认本轮进程已退出、活动请求为空。退出码说明实验按计划结束，不认证模型可靠性。

## 按冻结规则得到的研究决策

1. **输入获取方向有支持。**B 比 A 多正确 6 例、B 总体 9/12、可作答 7/8，达到预注册的描述性信号阈值。对有限短输入，程序完整收集值得保留为后续设计条件；收益归属于输入获取方式，不能记作 HCL 改进或自主导航能力提升。
2. **映射尚未满足预定可用条件。**虽然达到 4/6 可信正确，但只有 Anion gap 和 RASS 两类通过，MME 两例均未形成完整证据链，没有满足“覆盖三类计算”的要求。不能只看 4/6 就宣布可以进入下一门禁。
3. **剩余重点明确。**在完整输入条件下，优先研究派生参数的多来源依赖、转换说明，以及冲突证据下的终止决策，并保留范围守卫。当前无需把主要投入转向分页平台、扩大运行预算或更换模型；这不是排除以后使用对照模型。

本轮只完成诊断与交付，不自动实施后继修改或启动 HCL。导航新面板、映射旧开发用例均为小型合成测试，不能代表独立患者验证、真实临床泛化或医学 H0 已通过。v5 0/18 与 v6 提交 6/6、导航 2/6、映射未运行的结果保持原样。
