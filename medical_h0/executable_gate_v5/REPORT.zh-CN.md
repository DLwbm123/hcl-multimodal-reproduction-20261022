原始分布式数据包含 32 个源任务、239 个输出。全量初始身份目录的状态为 unregistered 199、enabled 17、mapped 15、disabled 8；这些是当时注册表的状态，不等于领域库不存在相应公式，更不能直接当作最终覆盖率。

最终冻结 L1 六目标、L2 六目标、锚点 A 六目标（两类技能各三）。它们分别来自 5、4、4 个源任务组，组间不重叠，每组最多两个目标。18 个目标的可见输入、公式变体和输出约定均可建立参考执行链，并与原 benchmark 输出相符。选择不依赖本轮模型表现；候选 MELD 在模型启动前因输出/公式版本约定不合被排除，单位大小写解析也仅在冻结前的 CPU 核查阶段修正。

旧六个诊断目标未进入本轮；旧六目标的来源组没有进入 A。L1/L2 开发面板允许同来源组内的其他目标。旧选择组被明确改作本轮开发用途，历史划分和历史结果均保留。冻结协议的 `panel.exclude_old_six_and_source_groups` 漏写了来源组排除只适用于 A/S/T 的范围，详见保留原文件的 [勘误](PROTOCOL_ERRATA.json)。该勘误没有改变输入、代码、阈值或运行结果。

所有 32 个源任务均已在更早实验中被模型评测过。13 个互不重叠的源任务组不等于 13 名独立患者；A 也不是全新确认集。输入是基准提供的 root_inputs，时间戳、sample_type 等元数据含启发式生成内容，field/value 文本才是测量含义依据。尚未建立至少 12 个全新来源组的 24 目标确认集；未来 HCL 数据就绪条件仍不满足。

## 实施与冻结

模型为已有共享 Qwen2.5-VL-7B-Instruct，BF16、greedy、sdpa；MedicalHarness LangGraph 循环与 Qwen-Agent Nous 调用协议沿用记录的上游版本。公式体保持不变，限定 15 个命名计算 profile。模型获得显式 calculator、patient、episode、输出约定，未获得参考参数或答案。这是显式任务范围下的文本工具验收，不代表自主发现目标、完整官方环境、视觉工具验收或 OS sandbox。

接口采用单一 bindings 数组，每个参数携带 value、fact_ids 和转换说明。临床输入必须显式给出；限定 profile 之外的算法选项使用已说明的库默认值，不以默认值补临床观测。执行器检查已读取事实、患者/episode 一致性、类型与域，语义支持由独立评价器审计。成功结果不可变；提交只能引用 result_id，弃答/失败必须说明原因。当前 profile 的参数直接引用事实，仅 sPESI 分类派生具有 result-to-result 链，不宣称通用中间结果依赖图。

CPU 阶段通过 13 项合成契约测试、非法调用原始历史保留检查，以及全部 18 条参考执行—提交—评分链；模型调用为 0。这些检查证明参考路径可执行，不能替代模型验收。冻结提交为 `469cde3`。部署依赖是既有源码副本，版本来源记录在 BASE_LOCK；未重新做逐字节身份验证。

“数值正确”也要求实际成功提交，不能用中间计算替代。两次来源与参数正确的中间计算均卡在提交环节。L1/L2 各至少两个可信正确且来自两个来源组、A 每类技能至少一个可信正确且覆盖两个来源组的门槛均未达到。

全部 18 个目标都有结束记录，全部两次接受计算（包括未提交的结果）完成独立参数/来源检查和人工逐项转换文本复核，没有未审定的接受计算。这里的人工复核由本次代理完成，不代表临床专家验证。`engineering_valid=true` 仅表示本轮按冻结程序完整结束并保留可评分记录，不意味着接口设计已经可靠。

主要失败证据如下，目标计数可重叠：

- 191 次实际生成中，原始 tool_call 外层 JSON 有 64 次无效、127 次有效；经完整 schema 检查后，共 90 次非法调用、101 次合法调用。原始输出保留，未用自动 JSON 修复将失败改判成功。
- 16/18 目标出现 JSON 格式错误；模型收到错误后常重复缺少闭合括号的调用。
- 9/18 目标出现证据范围或未读取来源错误；15/18 目标结束时未读完事实，15/18 仅发起一次事实读取。未读完本身不计错，但与错误证据定位同时出现，表明分页导航仍不可靠。
- 两个已正确计算的目标在提交时添加不适用字段、null 或混用 success/abstain 参数，最终丢失提交。公开 schema 只将 status 标为必填，条件互斥要求由运行时进一步检查；这一接口表达仍未帮助模型稳定完成提交。
- 被拒绝调用中还存在不合理语义推断，例如将功能活动能力字段当作既往病史的否定证据。不能把全部失败归结为 JSON，也不能将被拒绝调用中的参数视为有效临床结论。

14 个 stuck 与 4 个明确弃答都保留在 18 目标分母中。未因部分正确计算、正常退出或 CPU 检查通过而放宽门槛。
